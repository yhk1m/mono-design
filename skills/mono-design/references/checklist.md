# 끝내기 전 점검표

결과물을 넘기기 전에 하나씩 확인한다. 어긴 곳이 있으면 고치고 다시 확인한다.

## 색

- [ ] 내용은 흑백과 회색 단계뿐이고 강조색은 `--accent`, `--accent-2` 하나 계열만 쓴다. 다른 색을 새로 만들지 않았다(분류 이름표 `--c-1`~`--c-7` 제외).
- [ ] 강조색은 숫자, 핵심 상자, 선택 상태에만 있다. 헤더, 메뉴, 서랍, 푸터, 슬라이드 헤더에는 없다.
- [ ] 작은 회색 글자(출처, 날짜, 설명, 도움말)는 `--g5` 이상이고, `--g1` 면(안내 상자, 표 머리, 팝업) 위에서는 `--g6` 이상이다. `--g4`는 장식, 비활성, 큰 placeholder에만 썼다.
- [ ] 색은 토큰으로 썼다. `#000`, `#fff`를 직접 쓴 곳은 검은 푸터, `.section--deep`, 슬라이드 검은 장뿐이다.

## 글자

- [ ] 큰 제목 굵기는 400 이하다(첫 화면 400, 속 페이지 200, 구역 300, 슬라이드 400).
- [ ] 굵기 600 이상은 작은 이름표, 카드 제목, 버튼, 표 머리 같은 작은 글자에만 있다.
- [ ] 이모지가 없다. 아이콘은 선 SVG(`stroke: currentColor`, 채움 없음)이고, 아이콘만 있는 버튼에 `aria-label`이 있다.
- [ ] 보이는 글에 가운데 점과 긴 대시가 없다. 어색한 명사형 어미와 비유가 없다.
- [ ] 빌려 온 사실, 숫자, 그림에 출처 줄(`.m-source`, 슬라이드 `.src`)이 있다.

## 모양

- [ ] 모서리는 0이다. 버튼, 알약, 쪽 번호만 2~3px, 칩만 완전히 둥글다. 선택 표시 막대도 직각이다.
- [ ] 그림자와 그라데이션이 없다(실물 사진 예외 하나만).
- [ ] 구역과 목록은 줄로 나눴다: 위 검은 1px, 행 사이 `--g2`, 강조 카드는 위 3px. 상자를 겹겹이 두르지 않았다.
- [ ] 강조는 검은 상자(`.m-key`, `.inv`) 하나로 했고, 한 상자에 핵심 하나다.

## 웹 화면

- [ ] 390px에서 가로 넘침이 0이다(`document.documentElement.scrollWidth - innerWidth === 0`).
- [ ] 휴대폰에서 누르는 곳이 모두 44px 이상이다.
- [ ] 다크 모드에서 모든 글자가 읽힌다. 다크 강조색 글자는 `--bg` 위에만 있다.
- [ ] 1440px, 1023px, 767px, 390px에서 헤더, 메뉴 줄, 서랍이 맞게 바뀐다. 서랍은 Esc로 닫힌다.

## 슬라이드

- [ ] 모든 장에서, `.frag`를 다 보인 뒤에도 1920x1080 밖으로 넘치는 요소가 없다. 헤더 장 이름(`data-sec`)도 한 줄에 다 들어간다.
- [ ] 인쇄 미리보기(P)에서 한 장에 한 쪽이고, 검은 장이 흰 바탕으로 나온다.
