# 그래프

그래프는 `assets/mono-viz.js`로 그린다. 라이브러리 없이 SVG를 만들고 색은 모두 CSS 변수라 테마, 다크 모드, 인쇄가 저절로 맞는다. 손으로 SVG 좌표를 계산하지 않는다. 예시는 `assets/viz-template.html`.

## 1. 붙이는 법

- **웹:** mono-viz.js 내용을 `<script>`에 붙이거나 옆에 복사해 `<script src="mono-viz.js">`. mono.css 다음에 둔다.
- **슬라이드:** 템플릿에 이미 들어 있다(`MONO_VIZ:START` 블록). 아래 "그래프와 지도 장" 스크립트에서 값만 바꾼다.
- 그릴 자리는 너비가 있는 빈 `<div id="...">`. 높이는 알아서 정한다(웹 240~420px, 슬라이드 500px, 가로 막대와 100% 띠는 줄 수만큼). 바꾸려면 `height`.
- 요소 너비가 바뀌면 다시 그린다. `.slide` 안이면 슬라이드 크기(글자 20px, 선 3px)로 그린다.
- 모든 함수는 `{ update(새 옵션) }`을 돌려준다.

## 2. 공통 옵션

| 옵션 | 뜻 |
|---|---|
| `unit` | 왼쪽 위 단위 줄. `'(단위: 만 명)'` |
| `source` | 아래 출처 줄. `'자료: 통계청'`. 슬라이드는 장의 `.src`에 쓰고 비워 둔다 |
| `title` | 화면 읽기 프로그램용 이름 |
| `height` | 높이(px) |
| `format` | 숫자 글자 함수. 기본은 천 단위 쉼표, 소수 한 자리 |

## 3. 일곱 가지

```js
// 1. 세로 막대: 계열 둘까지 묶음, stacked: true 로 누적
MonoViz.bar('#a', { unit: '(단위: 명)', labels: ['세계지리', '한국지리'],
  series: [{ name: '2025', values: [62, 88] }, { name: '2026', values: [70, 81] }] });
// 계열 하나면 values 만. 짚을 막대 하나: highlight: 3 (계열 여럿이면 { series: 1, index: 3 })

// 2. 가로 막대: 이름이 길거나 항목이 6개 넘을 때
MonoViz.hbar('#b', { unit: '(단위: %)', labels: ['지형', '기후', '인구'], values: [72, 58, 81], highlight: 1 });

// 3. 꺾은선: 범례 대신 선 끝에 이름. highlight: 계열 번호. zero: true 면 0부터. dots: true 면 모든 점
MonoViz.line('#c', { unit: '(단위: %)', labels: ['1990', '2000', '2010'],
  series: [{ name: '한국', values: [74, 80, 82] }, { name: '일본', values: [77, 79, 91] }], highlight: 0 });

// 4. 산점도: 이름은 짚을 점에만. trend: true 면 회색 추세선
MonoViz.scatter('#d', { unit: '기대 수명(세)', xTitle: '1인당 소득(천 달러)', trend: true,
  points: [{ x: 4, y: 68 }, { x: 34, y: 83, label: '한국', highlight: true }] });

// 5. 100% 띠: 원 그래프 대신
MonoViz.share('#e', { parts: ['1차', '2차', '3차'], rows: [{ label: '1970년', values: [50, 20, 30] }] });

// 6. 기후 그래프: 기온 12개(℃), 강수량 12개(mm). unit 을 비우면 연평균 기온과 연 강수량을 적는다
MonoViz.climate('#f', { name: '서울', temp: [/* 1~12월 */], rain: [/* 1~12월 */] });

// 7. 인구 피라미드: ages 는 어린 연령대부터. names 기본 ['남자', '여자']
MonoViz.pyramid('#g', { unit: '(단위: %)', ages: ['0~4', '5~9'], male: [1.4, 2.0], female: [1.3, 1.9] });
```

## 4. 무엇을 고를까

| 보여 줄 것 | 그래프 |
|---|---|
| 항목끼리 크기 비교, 항목 6개 이하 | 세로 막대 |
| 이름이 길거나 항목이 많음, 순위 | 가로 막대 |
| 시간에 따른 변화 | 꺾은선 |
| 두 값의 관계 | 산점도 |
| 전체 속 비율, 구성 비교 | 100% 띠 |
| 한 곳의 월별 기온과 강수 | 기후 그래프 |
| 연령과 성별 구성 | 인구 피라미드 |
| 숫자 하나, 둘 | 그래프 대신 큰 숫자(`.m-num`, 슬라이드 `.stat`) |

## 5. 규칙

1. **색은 흑백 순서.** 계열 색은 `--fg`, `--g5`, `--g3` 순서로 셋까지. 넷 이상이면 분류 색 `--c-1`~`--c-7`. 새 색을 만들지 않는다.
2. **강조색은 짚을 값 하나.** `highlight`를 쓰면 그 계열의 나머지는 `--g3`(꺾은선은 `--g4`)로 물러나고 짚은 값만 `--accent`. mono 테마에서는 강조가 검정이라 나머지가 회색으로 물러나는 것으로 짚는다.
3. **축은 기준선 하나.** 아래 기준선 1px `--fg`, 가로 눈금선 1px `--g2`. 세로 눈금선, 눈금 표시, 테두리 상자는 그리지 않는다.
4. **글자.** 축 글자 `--g5`, 숫자는 폭이 같은 숫자. 단위는 왼쪽 위, 출처는 왼쪽 아래, 범례는 오른쪽 위. 그래프 제목은 그래프 밖 HTML 제목으로 쓴다.
5. **값 글자는 막대 12개 이하일 때만.** 굵기 600. 그보다 많으면 축 눈금으로 읽게 한다.
6. **원 그래프, 도넛, 3D, 그림자, 그라데이션, 둥근 막대 금지.** 비율은 100% 띠.
7. **꺾은선은 웹 2px, 슬라이드 3px.** 점은 끝점에만. 범례 대신 선 끝 이름.
8. **인쇄.** 그래프는 자료라 인쇄해도 색을 그대로 둔다(검은 면 회색 바꾸기에서 뺀다).
9. **휴대폰.** 그래프는 자기 상자 너비에 맞춰 다시 그려진다. 세로 막대의 항목 이름이 겹치면 가로 막대로 바꾼다.

## 6. 슬라이드에 넣기

슬라이드 템플릿의 "15-1. 그래프" 장을 복사한다. `.two` 두 칸에 하나씩, 또는 `.bd` 안에 하나만 크게. 그릴 자리에 `.frag`를 붙이면 하나씩 보이기도 된다. 장 아래 `.src`에 출처를 쓰고 `source`는 비운다. 아래 `<script>` "그래프와 지도 장"에서 자리 id와 값을 바꾼다.

## 7. 라이브러리가 꼭 필요할 때

확대, 마우스 따라 값 보기, 수천 개 점처럼 mono-viz.js에 없는 기능이 필요하면 라이브러리를 써도 된다. 그때도 위 규칙(색 순서, 기준선 하나, 눈금선 가로만, 글자색)을 그 라이브러리 설정으로 똑같이 맞춘다.
