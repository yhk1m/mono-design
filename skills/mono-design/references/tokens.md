# 토큰

값의 원본은 `assets/mono.css`다. 이 문서와 mono.css가 다르면 mono.css를 따른다. 슬라이드 템플릿은 같은 회색 단계를 자기 `<style>` 안에 따로 갖고 있다(라이트 전용).

대비는 WCAG 기준이다. 본문 글자 4.5:1, 큰 글자(24px 이상, 또는 18.66px 이상이면서 굵기 600 이상)와 줄, 아이콘 3:1.

## 1. 회색 단계

| 토큰 | 라이트 | 다크 | 쓰임 | 쓰지 말 것 |
|---|---|---|---|---|
| `--k` | `#000` | `#000` | 라이트의 글자, 검은 버튼, 목록 위 검은 줄 | 다크에서 글자색으로 직접 쓰기. 글자는 `--fg`를 쓴다 |
| `--w` | `#fff` | `#fff` | 라이트의 바탕 | 다크에서 바탕으로 직접 쓰기. 바탕은 `--bg`를 쓴다 |
| `--bg` | `#fff` | `#000` | 페이지 바탕, 서랍, 입력칸 바탕 | |
| `--fg` | `#000` | `#fff` | 본문 글자, 검은(다크에서는 흰) 버튼, 강조 줄 | |

| `--scrim` | `rgba(0,0,0,.6)` | `rgba(0,0,0,.7)` | 서랍, 팝업 뒤 막 | |

대비 숫자 (라이트, 흰 바탕): `--g5` 4.54:1, `--g6` 6.29:1, `--g7` 9.89:1. (다크, 검은 바탕): `--g5` 7.93:1, `--g6` 11.06:1. 다크 `--g4`(#767676)는 검은 바탕 4.62:1이지만 `--g1` 위에서는 3.83:1이라 역시 작은 글자에 쓰지 않는다.

### 검은 푸터와 검은 장 구분

두 모드 모두 바탕 `#000`. 글자 `#fff`, 보조 글자 `#d4d4d4`(14.17:1), 안쪽 줄 `#434343`. 푸터 위에는 1px `--g2` 줄을 둔다. 다크 모드에서 검은 페이지와 검은 푸터의 경계가 이 줄로 보인다. 푸터 색은 토큰이 아니라 고정값이다. 다크 모드에서도 바꾸지 않는다.

### 인쇄용 회색 `--print-fill`

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--print-fill` | `#e1e1e1` | 인쇄와 PDF에서 검은 면 대신 쓰는 회색 면. 글자는 검정 |

검은 면은 종이에서 잉크를 많이 먹는다. `@media print`에서 검은 버튼, 핵심 상자(`.m-key`, `.inv`), 선택된 알약과 칩, 채운 이름표, 짙은 구역은 `--print-fill` 바탕에 검은 글씨가 되고, 검은 푸터는 흰 바탕에 위 1px 검은 줄, 슬라이드 검은 장 구분은 흰 바탕이 된다. 다크 모드로 보다가 인쇄해도 모든 토큰이 라이트 값으로 돌아간다. 분류 색 이름표처럼 작은 색 면과 막대그래프는 그대로 둔다.

## 2. 테마 (`data-tone`)

`<html data-tone="mono|navy|blue">`. 기본 `mono`. 강조색 토큰은 넷이다.

- `--accent`: 큰 숫자, 핵심 상자 바탕, 선택된 알약, 막대 하나
- `--accent-2`: 두 번째 숫자 강조(`.m-num--2`, 슬라이드 `.count b`)
- `--deep`: 어두운 구역 바탕(`.section--deep`), 흰 글씨
- `--on-accent`: 강조색 바탕 위 글자색

| 테마 | 라이트 `--accent` | 라이트 `--accent-2` | `--deep` | 다크 `--accent` | 다크 `--accent-2` | 다크 `--on-accent` |
|---|---|---|---|---|---|---|
| `mono` | `#000` | `#000` | `#222` | `#fff` | `#fff` | `#000` |
| `navy` | `#122347` | `#704259` | `#44515f` | `#4471d0` | `#a16081` | `#fff` |
| `blue` | `#002f98` | `#e50000` | `#052645` | `#2569ff` | `#ed0000` | `#fff` |

대비:

| 색 | 흰 바탕 위 글자 | 흰 글씨를 얹을 때 | 검은 바탕 위 글자 | `--g1` 다크(#1a1a1a) 위 글자 |
|---|---|---|---|---|
| `#122347` | 15.47 | 15.47 | | |
| `#704259` | 8.04 | 8.04 | | |
| `#002f98` | 11.29 | 11.29 | | |
| `#e50000` | 4.85 (`--g1` 위 4.45) | 4.85 | | |
| `#4471d0` | | 4.65 | 4.52 | 3.74 |
| `#a16081` | | 4.66 | 4.51 | 3.73 |
| `#2569ff` | | 4.62 | 4.54 | 3.77 |
| `#ed0000` | | 4.56 | 4.60 | 3.81 |

규칙:

- 다크 강조색은 검은 바탕 4.5:1을 겨우 넘는 값이다. **다크에서 강조색 글자는 `--bg` 위에만 둔다.** `--g1` 면(안내 상자, 표 머리, 팝업) 위에서는 3.7:1이라 24px 이상 큰 글자만 된다.
- 라이트 blue의 `--accent-2`(#e50000)도 `--g1` 위 작은 글자는 안 된다(4.45:1).
- 강조색은 헤더, 메뉴, 서랍, 푸터에 쓰지 않는다. 내용 안의 숫자, 핵심 상자, 선택 상태 표시에만 쓴다.
- 강조색은 내용 안에서만, 웹은 한 구역에 한두 군데, 슬라이드는 한 장에 한두 군데(같은 종류의 숫자 둘은 함께 칠해도 된다). 나머지는 흑백이다.

### 오류 색 `--danger`

입력 오류 글자(`.m-field__error`)와 오류 입력칸 테두리(`[aria-invalid="true"]`)에만 쓴다. 테마와 상관없이 같고, 강조색 대신 쓰지 않는다.

| 모드 | 값 | `--bg` 위 | `--g1` 위 |
|---|---|---|---|
| 라이트 | `#d40000` | 5.53:1 (#fff) | 5.07:1 (#f5f5f5) |
| 다크 | `#ff5c5c` | 6.94:1 (#000) | 5.75:1 (#1a1a1a) |

## 3. 분류 색 (`--c-1` ~ `--c-7`)

과목, 단원, 갈래 이름표(`.m-tag.c-n`) 전용. 직각, 흰 글씨, 두 모드 공통.

| 토큰 | 값 | 흰 글씨 대비 |
|---|---|---|
| `--c-1` | `#927037` | 4.57 |
| `--c-2` | `#4b6256` | 6.60 |
| `--c-3` | `#645169` | 7.18 |
| `--c-4` | `#455371` | 7.70 |
| `--c-5` | `#5e3939` | 9.90 |
| `--c-6` | `#90533f` | 6.01 |
| `--c-7` | `#3f3f46` | 10.44 (`.m-tag` 기본) |

`--c-1`은 처음 값 `#947238`이 흰 글씨 4.45:1이라 `#927037`로 조금 어둡게 했다. 되돌리지 않는다.

쓰지 말 것: 분류 색으로 글자 칠하기, 큰 면 칠하기, 강조색 대신 쓰기, 한 이름표에 여러 색. 같은 분류는 페이지 어디서나 같은 번호.

## 4. 글자

글꼴 `--font`: `"Pretendard Variable", Pretendard, "Malgun Gothic", "Apple SD Gothic Neo", sans-serif`. 웹은 Pretendard 1.3.9 가변 서브셋(jsdelivr), 슬라이드는 정적 CSS. 코드 `--mono`: `Consolas, "D2Coding", monospace`, 자간 0.

공통 규칙:

- 자간: 16px 이상 `-0.5px`(body 기본), 14px 이하 `0`. 큰 제목은 더 좁게: 44~72px `-1px`, 56px 숫자 `-1.5px`, 슬라이드 72px `-1.5px`, 120px `-2px`.
- 줄 간격: 28px 이상 1.2, 18~24px 1.4, 본문 1.6, 긴 글(`.t-long`, 안내 상자) 1.8.
- `word-break: keep-all`. 긴 주소만 `break-all`.
- **큰 제목은 가늘게.** 제목 굵기 200~400. 600~700은 16~18px 이름표, 카드 제목, 버튼, 표 머리 같은 작은 글자에만.
- 제목 줄바꿈은 `<br>`로 직접 넣는다. 한 줄에 한 덩어리 뜻.

## 5. 간격

단계: `--sp-4` 4, `--sp-8` 8, `--sp-12` 12, `--sp-16` 16, `--sp-20` 20, `--sp-24` 24, `--sp-32` 32, `--sp-40` 40, `--sp-60` 60, `--sp-80` 80, `--sp-120` 120. 이 밖의 값은 쓰지 않는다.

| 자리 | 데스크톱 | 휴대폰 (767px 이하) |
|---|---|---|
| 구역 위아래 `.section` | 120 / 120 (이어지는 구역은 위 0. 단 `.section--line`, `.section--deep`과 짙은 구역 바로 뒤 구역은 위 여백 유지) | 80 / 80 |
| 첫 화면 `.hero` | 위 120, 아래 240 | 위 80, 아래 120 |
| 구역 제목 아래 `.m-sec-head` | 40 | 40 |
| 격자 칸 사이 `.m-grid-2` `.m-grid-3` | 40 | 32 |
| 머리말 아래 `.m-eyebrow` | 20 | 20 |
| 리드 위 `.m-lead` | 32 | 24 |
| 버튼 줄 위 `.m-btns` | 40, 버튼 사이 12 | 같음 |

슬라이드: 양옆 140, 헤더 120, 본문 위 60 아래 100(`.bd`), 큰 화면 장은 위 40 아래 56(`.bd.fill`). 두 칸 사이 80, 세 칸 사이 64.

## 6. 너비와 나눔점

- 본문 너비 `--wrap` 1200px(`.wrap`). 넓은 첫 화면 1312px(`.wrap--wide`), 읽는 페이지 1080px(`.wrap--read`).
- 양옆 여백 `--gutter`: 1280 이상 100px, 768~1279 40px, 767 이하 16px.
- 나눔점(max-width): **1279**(햄버거 버튼 보임, 여백 40), **1023**(헤더 메뉴 대신 헤더 아래 옆으로 밀리는 메뉴 줄, 세 칸 격자가 한 칸으로), **767**(휴대폰: 헤더 64px, 여백 16, 글자 단계 줄임, 두 칸 격자 한 칸, 표가 카드처럼, 서랍 전체 화면, 테마 고르기는 서랍 안으로, 누르는 곳 44px).

## 7. 모서리

- 기본 0. 상자, 카드, 탭, 입력칸, 표, 팝업, 이름표, 서랍 모두 직각.
- 버튼, 알약, 쪽 번호, 테마 고르기 2px. 큰 버튼(`.m-btn--lg`) 3px.
- 거르기 칩(`.m-chip`)만 완전히 둥글게(999px).
- 예외: 슬라이드 휴대폰 틀(`.demo2 .shot`)은 실물 모양이라 40px.

## 8. 그림자와 그라데이션

- 그림자 없음. 팝업, 서랍, 카드에도 없다. 겹침은 막(`--scrim`)과 테두리로 나눈다.
- 유일한 예외: 책 표지 같은 실물 사진에만 `box-shadow: 6px 6px 12px rgba(0,0,0,.1)`.
- 그라데이션 없음. 글자 그라데이션, 배경 그라데이션, 흐림(blur) 유리 효과 모두 쓰지 않는다.

## 9. 구조를 만드는 줄

- 목록과 표는 위 검은 1px 줄(`--fg`)로 열고, 행 사이는 `--g2` 1px 줄. 세로줄, 줄무늬 행, 칸 바탕색 없음.
- 강조 카드는 위쪽 3px 검은 줄(`.m-card`). 테두리 상자로 감싸지 않는다.
- 선택 표시는 왼쪽 4x24px 직각 검은 막대(서랍 현재 항목). 둥근 막대 금지.
- 슬라이드 목록은 위 `--g3` 1px 줄, 행 사이 `--g2`.

## 10. 움직임

- 색, 바탕, 테두리, 투명도만 0.15초 `--ease`(`cubic-bezier(.4,0,.2,1)`). 슬라이드 헤더 장 목록 0.2초.
- 서랍과 막 0.4초. 슬라이드 하나씩 보이기(`.frag`) 0.4초, 12px 아래에서 올라오기.
- 첫 화면 등장 애니메이션, 튀는 움직임, 무한 반복 없음.
- `prefers-reduced-motion: reduce`이면 모든 전환을 끈다(mono.css 18절, 슬라이드 `.frag`).

## 11. 아이콘

- 선 SVG만. `.m-icon`: 24px, `fill: none`, `stroke: currentColor`, 굵기 1.5, 끝 `square`, 꺾임 `miter`. 작은 것 `.m-icon--sm` 18px. 슬라이드 `svg.ic` 28px.
- 채운 아이콘, 이모지, 색 아이콘 금지. 아이콘만 있는 버튼에는 `aria-label`.
