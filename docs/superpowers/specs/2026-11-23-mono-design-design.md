# 모노 디자인 (mono-design) 설계

날짜: 2026-11-23

## 목적

흑백 중심의 에디토리얼 디자인을 HTML 발표자료와 웹페이지(웹 도구 포함)에 한결같이 입히는 Claude Code 스킬. 사용자가 자주 쓰는 한 학원 패밀리사이트의 디자인 언어와, 그 언어를 옮긴 사용자의 발표자료(html.bgnl.kr/50, /34)를 근거로 값을 정했다.

## 결정 사항

- 이름: 모노 디자인, `mono-design`.
- 결과물 범위: HTML 슬라이드(1920×1080) + 웹페이지와 웹 도구. PPTX는 다루지 않는다.
- 로고와 브랜드: 원래 학원의 로고, 이름, 주소를 쓰지 않는다. 헤더 브랜드 자리는 발표자나 사이트 이름으로 채운다.
- 공개: GitHub 공개 저장소 `yhk1m/mono-design`(Claude Code 플러그인) + 로컬 설치. 공개본 어디에도 원래 학원 이름, 도메인, 사이트 이름을 쓰지 않는다. 테마는 색 이름으로 부른다.
- 다크 모드: 라이트 기본, 기기 설정(`prefers-color-scheme`)과 `data-theme="light|dark"` 버튼으로 전환.
- 테마: `data-tone="mono|navy|blue"`, 기본 `mono`.

## 근거 자료

- 측정 보고서: 패밀리사이트 8곳을 1440px, 390px에서 헤드리스 Chrome으로 측정 (scratchpad `sites/REPORT.md`, 캡처 56장).
- 발표자료 분석: `deck-REPORT.md`, 재사용 뼈대 `deck-skeleton.html` (23장).
- 제외: 같은 그룹의 온라인 사이트(어두운 바탕, 8~16px 둥근 모서리)는 이 디자인 언어가 아니므로 반영하지 않는다.

## 디자인 토큰

### 색 (라이트)

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--k` | `#000` | 글자, 검은 버튼, 강조 줄 |
| `--w` | `#fff` | 바탕 |
| `--g1` | `#f5f5f5` | 면, 비활성 탭, 안내 상자, 호버 바탕 |
| `--g2` | `#efefef` | 행 사이 가는 줄 |
| `--g2b` | `#e1e1e1` | 팝업 테두리, 쪽 번호 테두리 |
| `--g3` | `#d4d4d4` | 입력칸, 탭, 버튼 테두리, 목록 위 줄(슬라이드) |
| `--g4` | `#9f9f9f` | 출처, 작은 숫자, 비활성 칩 |
| `--g5` | `#767676` | 보조 글자, 메뉴 |
| `--g6` | `#606060` | 두 번째 글자 |
| `--g7` | `#434343` | 검은 바탕 위 구분 줄 |

검은 푸터와 검은 장 구분: 바탕 `#000`, 글자 `#fff`, 보조 글자 `#d4d4d4`, 줄 `#434343`.

### 다크 모드

바탕 `#000`, 면 `#111`/`#1a1a1a`, 글자 `#fff`, 회색 단계는 뒤집어서 `--g1 #1a1a1a`, `--g2 #262626`, `--g2b #2e2e2e`, `--g3 #434343`, `--g4 #767676`, `--g5 #9f9f9f`, `--g6 #bcbcbc`, `--g7 #d4d4d4`. 검은 버튼은 흰 버튼(글자 검정)이 된다. 구체 값은 구현 때 대비 4.5:1(본문), 3:1(큰 글자, 줄)을 계산으로 맞춘다.

### 테마 (`data-tone`)

| 테마 | `--accent` | `--accent-2` | `--deep` (어두운 구역) | 다크 모드 `--accent` |
|---|---|---|---|---|
| `mono` | `#000` | `#000` | `#222` | `#fff` |
| `navy` | `#122347` | `#704259` | `#44515f` | 밝은 남색(대비 4.5:1 이상으로 계산) |
| `blue` | `#002f98` | `#e50000`(숫자 강조) | `#052645` | 밝은 파랑(대비 계산) |

강조색은 헤더, 메뉴, 푸터에 쓰지 않는다. 내용 안의 숫자, 핵심 타일, 선택 상태 표시에만 쓴다.

### 분류 색 (`--c-1`~`--c-7`)

과목, 단원, 갈래 이름표용 차분한 색: `#947238` `#4b6256` `#645169` `#455371` `#5e3939` `#90533f` `#3f3f46`. 직각 이름표, 흰 글씨. 다크 모드에서도 같은 색(흰 글씨 대비 유지).

### 글자

- 글꼴: Pretendard(웹은 CDN `orioncactus/pretendard@v1.3.9` 정적 또는 가변 서브셋), 대체 `"Malgun Gothic", "Apple SD Gothic Neo", sans-serif`. 코드는 Consolas 계열.
- 자간: 16px 이상 `-0.5px`, 14px 이하 `0`. 큰 제목은 더 좁게(72px `-1px`~`-1.5px`, 120px `-2px`).
- 줄 간격: 28px 이상 1.2, 18~24px 1.4, 본문 1.6, 긴 글 1.8.
- `word-break: keep-all`.
- 큰 제목은 가늘게: 굵기 200~400. 600~700은 16~18px 이름표에만.
- 웹 크기 단계: 72(첫 화면 제목, 휴대폰 32) / 44(속 페이지 제목, 굵기 200) / 32(구역 제목, 200~300) / 24 / 20 / 18 / 16(본문) / 14 / 13 / 11(이름표).
- 슬라이드 크기 단계: h1 120/400, h2 72/400, h3 32/600, 본문 28/1.8, 머리말 24(g5), 출처 16(g4).

### 모양과 움직임

- 모서리 0. 버튼과 쪽 번호만 2px(큰 버튼 3px). 거르기 칩만 완전히 둥글게.
- 그림자 없음. 예외: 책 표지 같은 실물 사진에만 `6px 6px 12px rgba(0,0,0,.1)`.
- 그라데이션 없음.
- 구조는 줄로: 목록 위 검은 1px 줄, 행 사이 `--g2` 1px 줄, 강조 카드는 위쪽 3px 검은 줄, 선택 표시는 4×24px 직각 검은 막대.
- 움직임: 색과 투명도 0.15~0.2초 `cubic-bezier(.4,0,.2,1)`, 서랍 0.4초. 첫 화면 애니메이션 없음. `prefers-reduced-motion` 존중.

## 웹 화면 규칙

- 헤더: 104px, 흰 바탕, 왼쪽 이름(필요하면 1×16px `--g2` 구분선 뒤에 부제), 오른쪽 메뉴 18px/400 `--g5`, 호버와 현재 항목은 검정. 고정하지 않는 것이 기본.
- 본문 너비 1200px(넓은 첫 화면 1312px, 읽는 페이지 1080px). 양옆 여백 100px(1280 이상) / 40px(768~1279) / 16~20px(767 이하).
- 구역 간격 120px(첫 화면 위 120, 아래 240; 휴대폰 80/120). 간격 단계 4 8 12 16 20 24 32 40 60 80 120.
- 부품: 버튼(44px, 안쪽 8px 20px, 최소 너비 100px, 검은 채움 / 회색 테두리), 큰 버튼(58px), 폴더 탭, 검은 알약(선택된 거르기), 가는 줄 목록, 공지 표(머리 14/600, 행 `--g2`, "공지" 테두리 이름표), 쪽 번호(34px 정사각), 팝업(`--g1` 바탕, `--g2b` 테두리, 아래 58px 버튼 줄), 서랍 메뉴(460px, 휴대폰 전체 화면), 오른쪽 빠른 메뉴, 검은 푸터(2단, 연락처 4칸 격자), 밑줄만 있는 검색칸, 입력칸(직각, `--g3` 테두리, 초점 시 검정).
- 휴대폰: 64px 헤더 + 옆으로 밀리는 메뉴 줄, 햄버거로 서랍 열기. 앱 같은 도구는 아래 탭 막대(55~69px)도 허용. 가로 넘침 금지. 누르는 곳 최소 44px.
- 아이콘은 선 SVG. 이모지 금지.

## 슬라이드 규칙

- 1920×1080 고정 무대, 창에 맞춰 비율 유지 축소, 바깥 `#1a1a1a`.
- 슬라이드 양옆 140px. 위쪽 헤더 120px: 왼쪽 자료 제목 | 날짜와 장소, 오른쪽 장 이름 목록(현재 장 검정). 첫 장과 마지막 장은 헤더 없음.
- 엔진(50번 발표자료 기준): `data-sec`로 헤더 목차 자동 생성, `.frag` 하나씩 보이기, `data-go` 이동, 주소 `#n`, 키(→ ↓ PageDown Space Enter 다음, ← ↑ PageUp Backspace 이전, Home/End, F 전체 화면, P PDF), 모서리 버튼과 3px 진행 막대, iframe 안에서 키 전달, 인쇄 시 한 장에 한 쪽, 검은 장은 흰 바탕으로 인쇄, 모든 `.frag` 보이기. QR은 선택(문자열 설정 시 오른쪽 위).
- 부품 목록(뼈대에서 정리): 표지, 강사 소개, 목차, 검은 장 구분(두 자리 번호 + 제목), 마무리 / 두 칸, 세 칸, 레인 / 줄 목록(rows, steps, tt, chk), 연표와 개수, 막대 / 위 3px 줄 카드 / 1px 검은 상자(질문, 흐름, 이름표), 검은 상자 흰 글씨 핵심 한 줄 / 인용, 코드, 브라우저 틀, 휴대폰 틀 / 화면 캡처, 데모 iframe, QR 모음 / 범례 막대.
- 문구: 키워드 중심, 어색한 명사형 어미와 비유 금지, 가운데 점과 긴 대시 금지, 빌려 온 사실에는 출처 줄.

## 스킬 구성

```
mono-design/
  .claude-plugin/plugin.json
  .claude-plugin/marketplace.json
  README.md                     (한국어 소개, 설치법, 예시 캡처)
  skills/mono-design/
    SKILL.md                    (언제 쓰나, 핵심 규칙 10개, 금지 목록, 작업 순서, 참고 파일 안내)
    references/tokens.md        (색, 다크, 테마, 분류 색, 글자, 간격, 모양, 움직임)
    references/web.md           (헤더, 레이아웃, 부품별 규격과 HTML 예, 휴대폰)
    references/slides.md        (무대, 엔진 API, 부품 목록과 예, 문구 규칙)
    references/checklist.md     (완성 전 점검표)
    assets/mono.css             (토큰 + 웹 부품, 라이트/다크, 세 테마)
    assets/web-template.html    (헤더, 첫 화면, 목록, 표, 탭, 팝업, 푸터 예시 페이지 + 테마/다크 버튼)
    assets/slides-template.html (엔진 + 부품 예시 장)
  examples/                     (README용 캡처)
  scripts/verify.mjs            (헤드리스 Chrome 검증)
```

로컬 설치: `~/.claude/skills/mono-design`에 skills 폴더 내용을 복사. 저장소와 로컬 복사본은 수정 시 둘 다 갱신한다.

## 검증

1. `scripts/verify.mjs`: 웹 템플릿을 3테마 × 라이트/다크 × 1440/390px로 띄워 캡처, 문서 가로 넘침 0, 지정 글자 쌍 대비 계산(본문 4.5:1, 큰 글자 3:1), 콘솔 오류 0. 슬라이드 템플릿은 모든 장을 1920×1080으로 캡처하고 슬라이드 밖으로 넘치는 요소가 없는지, 키 넘기기와 `#n` 이동이 되는지 확인. 헤드리스 Chrome은 `--disable-gpu`, 매번 새 프로필.
2. 공개본 검사: 저장소 전체에서 원래 학원 이름, 도메인, 사이트 이름 문자열이 0건.
3. 실사용 시험: 스킬 내용을 받은 새 에이전트가 (가) 수업 안내 웹페이지 1개, (나) 슬라이드 5장을 만들고, 점검표 기준으로 위반을 센다. 위반이 나오면 SKILL.md를 고쳐 다시 시험.

## 범위 밖

- PPTX 출력, 원래 학원 로고, 온라인 사이트의 어두운 디자인, 회전 배너(캐러셀) 부품.
